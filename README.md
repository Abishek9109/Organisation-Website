
# Nova Organization Website

A multi-page organization website developed using HTML, CSS, and JavaScript.

## Features
- Home page with About Us and Contact Us sections
- Departments and employee information
- Events and news updates
- Career opportunities
- Interactive buttons and hover tooltips
- Navigation between pages

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Clone or download this repository.
2. Open the project in VS Code.
3. Run `index.html` using Live Server.
